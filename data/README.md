Commune lists for the city picker were downloaded on 25 September 2026 from the French public administrative API:

- `https://geo.api.gouv.fr/communes?codeRegion=11&fields=nom,code&format=json`
- `https://geo.api.gouv.fr/departements/10/communes?fields=nom,code&format=json`

The files retain only the commune name and INSEE code, sorted by name. The transport departure and return arrival use Île-de-France; accommodation and return departure also support Aube.
